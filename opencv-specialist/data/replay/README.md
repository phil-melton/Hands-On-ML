### Provenance of the answers (why the targets are free to train on)

- Answers (`output`): generated by **Qwen2.5-Coder-32B-Instruct**, license Apache-2.0 (https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct; paper section 2.3).
  Apache-2.0 puts no restriction on training with outputs. This satisfies rule 5.
- Instructions (`input`): seed questions are 25,443 TACO algorithmic questions plus 1.43 M tasks that **Qwen2.5-32B-Instruct** (Apache-2.0) wrote from GitHub Python
  functions (OSS-Instruct, SelfCodeAlign seed pipeline); Genetic-Instruct then mutated and crossed them. The model used as the Genetic-Instruct "Instructor-LLM" is
  **not named** in the card or the paper (the Genetic-Instruct paper, arXiv:2407.21077, compares Mixtral-family and Qwen-family models). Unit tests and judge scores
  also come from Qwen2.5-Coder-32B-Instruct. No OpenAI/Anthropic/Google model is named anywhere in the card or paper.
- Contamination: the paper says instructions were n-gram decontaminated against evaluation benchmarks (open-r1 script); the benchmark list is not given.
  Not re-checked here (no MBPP+/HumanEval+ file is local). Because the project's forgetting check is MBPP+ (LOGBOOK success criterion 3),
  run a 13-gram overlap check of this file against the MBPP+ slice when Stage 6 builds it.

## What `replay.jsonl` is

600 rows, one per line, exactly:
`{"messages": [{"role": "user", "content": <input>}, {"role": "assistant", "content": <output>}], "source": "nvidia/OpenCodeInstruct@8f3ba5bafe4d6e8db46082cf7ae6741bc370604d", "license": "CC-BY-4.0", "id": "<dataset row id>"}`

- `user` = the dataset's `input`, `assistant` = its `output`, both byte-for-byte unchanged. Every `output` is already exactly one fenced ```` ```python ```` block
  with no prose outside it (checked: 100,000 of 100,000 rows in the shard), so no reformatting was needed.
- No system message. Add the Modelfile SYSTEM string when assembling `data/train.jsonl` (rule 7).
- Row order is a seeded shuffle (seed 20261022), so any prefix, e.g. the first 300 rows, is approximately a stratified random sample.
- SHA-256 of `replay.jsonl`: `d74d3503e8c6731458a15d15b99513c8e2bd38336992346a575696d0e7f7eb22`.

## Filters (applied in this order; counts are rows remaining)

| Step | Rows |
|---|---|
| Shard `train-00000-of-00050` | 100,000 |
| Answer is one ```` ```python ```` block and the code passes `ast.parse` (Python-only, contains code) | 100,000 |
| All unit tests pass (`average_test_score == 1.0` and every `tests_execution_status` is "pass"; the dataset's own execution result) | 34,733 |
| LLM-judge: minimum of the three scores >= 4 (dataset's `llm_judgement`) | 23,329 |
| Drop any prompt or answer matching `cv2`, `opencv`, `open-cv`, `cv.<name>`, `computer vision` | 23,324 |
| Answer <= 800 words (nothing was dropped here; the longest answer in the shard is 677 words) | 23,324 |
| Drop prompts that name another target language (Java, C++, ...) or contain CJK characters | 23,304 |
| Exact dedupe: normalized prompt text, and AST-normalized code with docstrings removed | 20,238 |
| Seeded stratified sample, with a cap of 2 per first top-level function/class name and a 3-word-shingle Jaccard < 0.5 near-duplicate check on prompts | **600** |

Sampling strata: prompt style x (domain, generation_algorithm). Prompts open with the dataset's competitive-programming template
("You are given ...", "You are tasked ...") in 93.8 % of the pool, so differently phrased prompts ("Implement a ...", "Given a list ...") were oversampled to 25 % of the file.

| Style | domain / generation_algorithm | Pool | Kept |
|---|---|---|---|
| template | generic / self-instruct | 13,248 | 314 |
| template | generic / evol-instruct | 3,537 | 84 |
| template | algorithmic / self-instruct | 2,207 | 52 |
| other | generic / self-instruct | 871 | 105 |
| other | generic / evol-instruct | 203 | 24 |
| other | algorithmic / self-instruct | 172 | 21 |

The first 3,000 rows of the shard are all `generic` (the shard is not shuffled by domain), so the sample was drawn from the whole filtered shard, not from its head.
The brief asked for about 3,000 rows; the smallest pinned unit that can be fetched reproducibly is one shard (100,000 rows, 127 MB), and the datasets-server
only serves a partial parquet conversion (1.4 M of the 5 M rows), so the shard was downloaded whole and 600 rows were selected from the 20,238 that survive the filters.

## Style caveats

- Narrow prompt style: 584 of 600 prompts contain a "Sample Input" section even after the oversampling; 449 open with "You are given/tasked".
  They are closer to competitive-programming statements than to MBPP's "Write a function to ...".
- Answers are code only (docstring included, no explanation): 205 end with top-level `print(...)` example calls, 21 have an `if __name__ == "__main__"` guard,
  60 use type hints, 61 define a class, 119 have imports. This matches the project's answer format (a fenced python block, no prose).
- Synthetic, not human-written. 19 messages contain email addresses, all placeholders (example.com, example.org, domain.co.uk, ...); 9 contain URLs
  (example.com, localhost, kubernetes.default, api.github.com, socialmedia.com). No hard-coded secrets and no instruction-like text aimed at a reader
  (8 matches of "ignore/disregard", all inside ordinary task wording such as "ignore case").
